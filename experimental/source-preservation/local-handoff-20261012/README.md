# Local handoff helper source

Two inert snapshots preserve the byte-verified data transfer and the content-addressed source/configuration/save archive used to retire the local Wine checkout. They raise before imports or original logic. Exact original hashes and explicit checkout-path redactions are recorded in the manifest. No game, save, pairing, shader, archive or rollback payload is included here.

The actual private handoff is independent of the public source archive and remains ignored in the receiving project. Rebuilding historical output requires matching input sources; deleting intermediates does not convert failed tests into passes.
